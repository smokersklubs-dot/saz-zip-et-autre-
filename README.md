# saz-zip-et-autre-

Moteur industriel et Dashboard de simulation tarifaire & rétro-ingénierie pour packaging Mylar, Doypack et sacs multicouches (Miaobaojia V5.0.2).

## Fonctionnalités
- **Bi-technologie intégrée** : Impression Numérique (HP Indigo, 250 à 10 000 pcs) et Héliogravure (cylindres cuivre, 10 000+ pcs).
- **Catalogue de 7 types de sacs** : Doypack (sac debout), 3 soudures plat, octogonal fond plat, accordéon, 4 côtés, soudure centrale, bobines.
- **Pilotage de revente flexible** : Marge commerciale %, coefficient multiplicateur ou prix fixe unitaire.
- **Visualisations temps réel** : Dégressivité des volumes, donut de décomposition des coûts usine, estimation du poids et du carton.
- **Mode 100% furtif** : Exécution hors-ligne sans requêtes réseau vers les serveurs de l'usine.

## Lancement local
```bash
npm install
npm run dev
```
Accéder ensuite sur `http://localhost:3000/`.
